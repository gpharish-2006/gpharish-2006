# 🚀 Projects:

### 📌 Travel & Tourism
AI-powered Travel & Tourism Web App that helps users discover places to tour across regions with the assistance of an integrated AI chatbot.

### 📌 Smart Career Guidance
An AI-powered career guidance platform that helps students discover suitable tech career paths through personalized quizzes, skill analysis, and interest-based recommendations.

### 📌 AI Resume Analyser
An AI-powered resume analyzer that uses RAG and NLP transformers to evaluate resumes against job descriptions, calculate ATS scores, extract key skills, and provide an interactive AI chatbot.

### 📌 Rail-Opt
Ingests defect logs across Engineering (TMS), Signalling & Telecom (SMMS), and Traction Distribution (TDMS), scoring defect criticality via AI risk models and auto-generating consolidated Shadow Mega-Blocks using Google OR-Tools CP-SAT constraint solvers.

### 📌 Resolve-Net
A full-stack complaint management platform where citizens can register complaints, track resolution status, upload issue images, and interact with an admin dashboard.
